## 🌟 විශේෂාංග (Key Features)

1. **Google Sheets Live Sync:**
   - ඔබගේ Google Sheet එකෙන් කෙළින්ම දත්ත කියවා තත්පර කීපයකින් නැවුම් වාර්තා සකසයි.
2. **දිනපතා දත්ත සුරැකීම (Daily Snapshot SQLite Persistence):**
   - දිනපතා ගනුදෙනු එක් කළ පසු `💾 අද දින වාර්තාව Save කරන්න` බොත්තම එබූ විට ස්වයංක්‍රීයව `repayments.db` නම් SQLite Database එකේ සියලු දත්ත (Targets, Achieved, Variance, Daily Targets) සුරැකේ.
3. **Daily Required Target Calculator:**
   - සෙනසුරාදා සහ ඉරිදා හැර මාසයේ ඉතිරි වැඩකරන දින ගණන ස්වයංක්‍රීයව ගණනය කර, ඉලක්කය සම්පූර්ණ කිරීමට එක් එක් නිලධාරියා අද දින එකතු කළ යුතු මුදල පෙන්වයි.
4. **Dark Theme Target Report & PNG Download:**
   - Classic / Dark theme නිලධාරී ඉලක්ක වගුව (Group Iresha vs Group Dila) සහ එක් ක්ලික් එකකින් PNG පින්තූරයක් ලෙස Download කිරීමේ පහසුකම.
5. **1-Click WhatsApp Multi-Sender & Phone Manager:**
   - නිලධාරීන්ගේ දුරකථන අංක සුරැකීම සහ එක ක්ලික් එකකින් සියලුම නිලධාරීන්ට WhatsApp පණිවිඩ යැවීම.
